# Store publication: parked

**Decision (3 September 2026): we stay with GitHub releases.**

Google Play and the Microsoft Store want an account that is maintained, not a
one-off upload: questionnaires to click through whenever a policy changes, a
requirement to update for new API levels, and for new Play accounts a closed
test with 20 testers over 14 days on top. For a showcase app that is a cost
with no return.

Chatt is therefore released through [GitHub Releases](../../../../releases):
an APK, a Windows installer and a portable version. The release workflow builds
neither an AAB nor an MSIX package.

The graphics are generated by `app/tool/store_assets.py`; the output lives
outside the repository (`docs/publishing/assets/` is in `.gitignore`). The
README banner (`docs/promo.png`) comes from the same script and **is** in the
repository.

## If the decision changed

Three things to do before anything goes to a store:

1. The repository has to be public. A privacy policy needs a permanent address,
   and without one none of the questionnaires can be filled in.
2. Bring back the AAB build in the release workflow (Play does not accept an
   APK) and the MSIX step. Both were written and verified; they sit in the git
   history around phase 13.
3. **Autostart will not work under MSIX**: the package virtualises the HKCU
   registry, so an entry in `Run` never reaches the system. It has to be moved
   to a `StartupTask` in the manifest, or the switch has to be hidden in the
   Store build.
